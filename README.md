# Klask-Station

Eingabe-App für Klask-Turniere: Spielende tragen ihr Ergebnis am Tablet ein, es landet direkt in Kickertool 3.

- Läuft komplett im Browser, keine Installation.
- Der Kickertool-API-Token wird nur lokal auf dem jeweiligen Gerät gespeichert, nicht in diesem Repository.
- Demo ohne Kickertool: `?demo=12` an die Adresse anhängen.
